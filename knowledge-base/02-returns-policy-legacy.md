# Returns Policy — Legacy Version

> This document applied to orders placed before April 1, 2026. It has been superseded by RET-2026-01.

## Return window

Customers could return eligible merchandise within **45 calendar days of delivery**.

## Return shipping

Aster & Row provided one free domestic return label for each eligible order.

## Condition requirements

Items had to be unused, unwashed, and returned with original tags and packaging.

## Refund timing

Refunds were generally processed within 7–10 business days after inspection.
